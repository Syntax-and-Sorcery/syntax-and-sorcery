## Technologies

Next.js, React, TypeScript, Tailwind CSS, shadcn/ui with 8bitcn, CodeMirror, Supabase, the AI SDK with Claude, Vercel Sandbox.

## Prerequisites

Node 24 (24.15 or newer) or Node 26, and npm.

## Installation

```bash
npm ci
```

## Configuration

Copy `.env.example` to `.env.local`. For mock data, set `NEXT_PUBLIC_DATA_SOURCE=mock` and `CODE_RUNNER=local`.

## How to run

```bash
npm run dev
```

## How to test

```bash
npm run lint && npm run typecheck && npm run test:ci
```
